      2 Try to break the rules

      Each attempt is sent to the deployed contracts on a snapshot of the chain and rolled back afterwards, so the replayed season stays intact. The tag shows the auditability requirement of the article that the rule enforces.

      3 How this page works

      Same bytecode, same code paths

      The page loads the bytecode compiled from the repository's Solidity sources (Solidity 0.8.28, intermediate-representation pipeline, 200 optimizer runs, London rules) and executes it with the EthereumJS virtual machine. The replay plan, the consortium catalogue, the encodings and the off-chain LCA engine are the same JavaScript modules that the repository's tests use.

      A private test chain in this tab

      Chain ID 31337, zero gas price and one block per transaction, with block timestamps set to the dates of the case study. Accounts come from the public Hardhat test mnemonic and device signatures from deterministic test keys; nothing leaves your browser.

      Run it yourself

      Unpack this release, then run npm ci and npx hardhat test for the 107 tests, or npm run evaluate for the gas and storage reports. The demo is rebuilt with cd demo && npm ci && npm run build.
